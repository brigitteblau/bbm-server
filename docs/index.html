Hunda API

Generación y gestión de prótesis caninas 3D-printables. Esta página documenta cada endpoint tal como está desplegado ahora mismo en producción — pensada para integrarse directo desde el front.

Base URL https://bbm-server-hfq1.onrender.com
Sin autenticación (por ahora) JSON sobre HTTPS Hosteado en Render

Flujo típico

1
Paso 1 del front — cargar medidas
El usuario completa el formulario del perro. Opcional: llamar POST /prosthesis/socket/parameters para mostrar un preview de las medidas del socket sin guardar nada todavía.
2
Guardar la request
POST /prosthesis/requests guarda las medidas en la base y devuelve un request_id. Guardalo en el estado del front — es lo único que se necesita para el paso siguiente.
3
Paso 2 del front — generar el modelo
POST /prosthesis/requests/{'{'}request_id{'}'}/generate recalcula los parámetros desde la request guardada (no confía en el front), genera el STL y lo sube a Storage. Devuelve download_url, ya firmada.
4
Descarga
Usá download_url directo (válida 7 días), o el endpoint estable GET /prosthesis/generated/{'{'}filename{'}'} si preferís no guardar la URL firmada.

POST/prosthesis/requests/{'{'}request_id{'}'}/generate

Paso 2 del front: genera el STL a partir de una request ya guardada. Sin body — las medidas se leen de la base, nunca del front, para no confiar en datos que el cliente pueda mandar distintos. Usa Blender si está habilitado y disponible; si no, cae a un fallback que escala un STL base con trimesh.

CORS y errores

Orígenes permitidos hoy: http://localhost:3000 y https://bbm-server-hfq1.onrender.com. Si el front de producción va a vivir en otro dominio, hay que agregarlo a ALLOWED_ORIGINS en app/config.py antes de integrarlo — si no, el browser va a bloquear las requests aunque la API responda bien.

Todos los errores de validación (422) devuelven el shape estándar de FastAPI: {'{'} "detail": [...] {'}'}. Los errores 502/404 devuelven {'{'} "detail": "mensaje legible" {'}'} — están pensados para mostrarse directo o loguearse, no son mensajes internos.
